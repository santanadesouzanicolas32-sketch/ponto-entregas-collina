# Ponto de Entregas Collina

Sistema de ponto para entregadores do Empório Collina, em **um único arquivo** (`index.html`), pronto para o GitHub Pages.

- Entrada (15h ou 16h), pausas e saída, com a jornada prevista (23:20 / 00:40) e cálculo de atraso, hora extra e jornada incompleta.
- Cada entrega: **foto da comanda** (leitura automática do bloco e do apartamento **no próprio aparelho**, a foto não é enviada nem guardada) ou registro manual. O horário do registro não pode ser alterado.
- Avisos proativos (sem entregas, pausa longa, ritmo abaixo da média, fim da jornada), previsão da meta e relatórios de 7/30/90 dias, com planilha CSV.
- Os dados ficam **só no navegador** de quem usa (localStorage). Há backup e restauração em *Ajustes*.

Autotestes: abra `index.html?selftest`.
